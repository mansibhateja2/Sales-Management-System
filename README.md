# Sales Management System

## Project Overview
The Sales Management System is a data analytics project developed using Python, MySQL, and Microsoft Excel.

The project manages sales records, stores customer and product information, and analyzes sales performance.

## Tools & Technologies
- Python
- MySQL
- Microsoft Excel
- Pandas
- Matplotlib

## Project Features
- Sales data management
- Customer information management
- Product tracking
- MySQL database connectivity
- Data analysis using Python
- Excel dashboard and reporting

## Project Workflow
1. Create database and tables using MySQL.
2. Connect Python with MySQL.
3. Retrieve and analyze sales data using Python.
4. Export results into Excel.
5. Create an interactive Excel dashboard.

## Key Learning
- Python programming
- SQL queries
- Database connectivity
- Data cleaning and analysis
- Excel dashboard creation
